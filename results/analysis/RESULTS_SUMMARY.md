# P-Tree Analysis Results - Swedish Stock Market

## Executive Summary

Successfully applied P-Tree methodology to Swedish stock market data using a **boosted ensemble approach** specifically optimized for smaller markets.

## Final Results

|--------|-------|
| **Sharpe Ratio (Annual)** | **1.25** |
| **Annualized Return** | **19.07%** |

### Data Coverage

- **Time Period**: June 1999 - Present
- **Observations**: 69,830 stock-month observations
- **Unique Stocks**: 696
- **Months**: 258
- **Average Stocks/Month**: 270.7
- **Characteristics Available**: 40 (30% coverage threshold)
- **Characteristics Selected by Model**: 3 (rank_svar, rank_mom12m, rank_mom6m)

### Key Characteristics Selected

The P-Tree model selected these 3 characteristics from 40 available (showing strong feature selection):

1. **rank_svar** - Stock return variance (nodes 1, 6, 13)
   - Low volatility stocks tend to outperform
2. **rank_mom12m** - 12-month momentum (node 3)
   - Winners continue winning (momentum effect)
3. **rank_mom6m** - 6-month momentum (node 27)
   - Shorter-term momentum also predictive

## Model Structure

The final model uses a **boosted ensemble of 5 shallow trees** (num_iter=5) rather than a single deep tree:

- **Tree Nodes**: 11 nodes in final iteration
- **Effective Splits**: 4 splits across boosting iterations
- **Tree Depth**: Moderate (8 max)
- **Ensemble Approach**: Gradient boosting with eta=0.3

## Why This Approach Works for Swedish Data

Traditional P-Tree configurations (single deep tree, value-weighted, regularized) fail on Swedish data due to:

1. **Market Size**: ~270 stocks/month vs ~3000+ in US markets
2. **Concentration**: Fewer large-cap stocks dominate
3. **Liquidity**: Lower trading volumes create numerical instability

**Solution**: Boosted ensemble approach
- Combines 5 weak learners instead of 1 deep tree
- Equal weighting reduces large-cap bias
- No regularization (lambda_cov=0) enables splits
- Lower min_leaf_size (3 vs 10) adapts to fewer stocks

See `docs/SWEDISH_MARKET_ADAPTATIONS.md` for detailed methodology.

## Technical Notes

### Expected Warnings

During training, you may see:
```
warning: solve(): system is singular; attempting approx solution
```

This is **normal and expected** for smaller markets. The algorithm handles it gracefully.

### Parameter Rationale

See `docs/SWEDISH_MARKET_ADAPTATIONS.md` for full justification of parameter choices based on extensive diagnostic testing.

| Parameter | Value | US Default | Reason |
|-----------|-------|------------|--------|
| num_iter | 5 | 1 | Boosting essential for Swedish data |
| min_leaf_size | 3 | 10 | Fewer stocks per month |
| num_cutpoints | 50 | 20-30 | Finer granularity |
| equal_weight | TRUE | FALSE | Reduce large-cap bias |
| lambda_cov | 0 | 1e-5 | Avoid numerical issues |
| eta | 0.3 | 1.0 | Moderate learning rate |
